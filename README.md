# 抽奖系统

## 背景

- 需求方想通过"抽奖"的方式给老爸送一台 **vivo X200s 手机**（直接买他不愿意接受）。
- 做一个**手机端抽奖网页**（PC 测试、最终微信内 Android 打开使用），风格由极简 → 已升级为**多彩炫酷风**。
- 纯前端、无后端，数据存 `localStorage`，按手机号区分。

## 核心规格（以 `AGENTS.md` 为准）

- **登录**：首页登记姓名 + 手机号；手机号仅校验 11 位长度。
- **抽奖次数**：初始 **3 次**；**转发无限加次**（无每日上限），可无限次数抽。
- **转发**：点按钮 → 提示"已复制到剪贴板"（不真正复制）→ **10 秒倒计时**后次数 +1；中途退出网页也不丢次数（pending 任务持久化，回来后补发）。
- **奖品与概率**：8 槽位轮盘，各扇区概率均等。手机×1、5元话费券×1、10元话费券×1、感谢参与×5。
  - 手机：概率 **1/8**，**仅两个指定号**可中，且须**第 5 次起**才进抽奖池。
  - 指定号：`13925599313`（老爸）、`19868735951`（用户测试号）。
  - **老爸号**中手机后**封抽不能再抽**；**测试号不封**可继续抽。
  - 话费券/感谢参与可中无数次，不影响；其他所有号码永远中不了手机。

## 设计

- 进入网页先登记姓名、手机号码。

- 只有抽中手机，才弹出**收货地址确认信息**：完全由用户填写，不需要省、市等选择。

- 有**个人中心**页面：若没抽中手机，显示无奖品；抽中手机则显示奖品 + "待收取"。

- 界面为多彩/丰富风格（已弃极简），轮盘式，抽奖按钮有按下动效，中/未中都弹窗，中手机动画绚烂华丽（金色粒子 + 彩带）。

- 界面风格预览见 `previews/`（demo1 经典豪华 / demo2 多彩明快 / demo3 霓虹炫彩）。

## 要求

- 手机须**第 5 次起**才有机会抽中（`CONFIG.PHONE_DRAW_START = 5`，可在 `js/app.js` 顶部调整）。

- 存储针对某个手机号，内容存到本地（localStorage）；开发阶段有退出登录按钮用于测试，**正式版要求取消**（将 `js/app.js` 顶部 `CONFIG.IS_DEV` 改为 `false`）。

- 正式使用中，即使退出网页再进入也有当前账户记忆（`ll_session` 持久化）。

- 提供转发功能按键：点击后提示已复制链接，转发给朋友，每转发一次获得 1 次抽奖次数（无每日上限）。

- **只有 `13925599313` 与 `19868735951` 才能真正抽中手机**。

- 检查号码格式（仅长度）。
